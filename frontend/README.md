# HACKALEM AI: консультант Электрокомплект

Фронтенд на React, TypeScript и Vite: плавающий виджет ассистента для сайта ekt.kz. Главная страница локального проекта показывает демонстрационный каталог с круглой кнопкой AI справа внизу. Это не официальный сайт магазина. `?widget=1` показывает только прозрачный слой виджета для встраивания. Реальная модель, распознавание документов и корзина магазина требуют бэкенда.

## Запуск

Node.js 22.12+ и npm. В PowerShell:

```powershell
$env:Path = "C:\Program Files\nodejs;$env:Path"
cd frontend
npm.cmd install
npm.cmd run dev
```

Откройте адрес `Local`, выведенный Vite. Не используйте Live Server или открытие index.html как файла. Проверка типов и сборка: `npm.cmd run build`. Проверка поиска, вложений и API-контракта корзины: `npm.cmd test` (серверные ответы в тестах подменяются, реальных покупок нет).

## Что работает без сервера

- Поиск по 40 товарам из двух предоставленных JSON-файлов внутри диалога; найденные товары появляются в ответах помощника.
- Чат по умолчанию свёрнут в круглую кнопку справа внизу. Открывается поверх сайта, закрывается крестиком или Escape; история сохраняется при сворачивании. Новый диалог и перезагрузка очищают историю. Кнопка обсуждения на карточке передаёт товар в контекст.
- Для товара 515291 (027228 / 200300285_) добавлена подробная карточка: описание, свойства, остаток 23 шт. и все 24 склада. Данные сохранены в `src/data/product-515291.json`; Markdown-экранирование и ссылки из сообщения пользователя приведены к JSON. Остаток относится к предоставленному снимку, а не к текущему состоянию магазина.
- В данных товара есть конфликт: название и описание указывают 160 А, поле NOMINALNYY_TOK — 250 А. Предупреждение показывается в ответе и карточке. RECOMMEND содержит только ID и не считается перечнем проверенных аналогов. Сертификат не предоставлен.
- Демо-ответы используют локальный поиск, а не языковую модель. Уточняющие вопросы могут использовать товары предыдущего ответа.
- Сравнение свободных формулировок по правилам: «Что дешевле, 027228 или 027230?», «А какой из них лучше?», «Посоветуй недорогой автомат до 30 тысяч». Учитываются явные артикулы, категория, товары предыдущего ответа и бюджет. Сравниваются известные цены и характеристики, неизвестные не выдумываются. Без задачи и достаточных данных помощник уточняет критерии вместо утверждения о качестве или совместимости. Это ограниченный набор распознаваемых намерений, не понимание произвольной речи языковой моделью.
- Выбор нескольких файлов любого расширения, перетаскивание в поле сообщения, удаление перед отправкой, отправка без текста. Максимум 25 МБ на файл, 10 файлов и 50 МБ суммарно.
- TXT, CSV, TSV, JSON, MD, XML и LOG до 2 МБ проверяются локально на совпадения артикулов. Это поиск строк, а не полноценный разбор таблиц. PDF, Word, Excel, изображения и другие бинарные форматы принимаются, но их анализ доступен только через бэкенд. Демо явно сообщает об этом.
- При неизвестном остатке добавление в корзину блокируется. Демо не изменяет реальную корзину.

## Данные

`src/data/catalog-page-1.json` и `catalog-page-2.json` содержат исходные файлы пользователя без изменений. Поля: id, name, article, price, image, url, url_api_detail, offers. Массивы offers пустые: это НЕ означает нулевой остаток. Подробные данные товара 515291 объединяются с исходной выборкой по ID; у остальных 39 товаров остатки и полные характеристики неизвестны. Сертификаты и условия доставки/оплаты не предоставлены. Цена помечена как цена из выгрузки. Валюта интерфейса — тенге. Фотографии загружаются по исходным ссылкам ekt.kz, при ошибке показывается заглушка.

Рекомендации совместимых аналогов без полных технических данных не выдаются. URL детального API сохранён в данных, но напрямую из браузера не вызывается: доступ и CORS должны быть согласованы при интеграции.

## Встраивание

Соберите и разместите `dist` на HTTPS-домене. Добавьте перед закрывающим body сайта, заменив адрес на адрес размещённого фронтенда:

```html
<script src="https://assistant.example.com/embed.js" defer></script>
```

Скрипт создаёт iframe с `?widget=1`. В закрытом состоянии видна только кнопка, при открытии iframe расширяется. Сообщения изменения размера проверяются по origin и source; содержимое переписки через postMessage не передаётся. Для нестандартного пути можно задать `data-url="https://assistant.example.com/?widget=1"`. Политики CSP/frame-ancestors должны разрешать согласованный домен магазина. Встраивание на реальный ekt.kz в рамках этой работы не выполнялось.

## Контракт бэкенда

Задайте `.env.local` и перезапустите Vite:

```dotenv
VITE_CHAT_MODE=api
VITE_API_BASE_URL=/api
```

В production переменные применяются при сборке. Желательно проксировать /api на тот же origin, чтобы сессия магазина работала без сторонних cookies. При другом домене настройте CORS. Секреты провайдера ИИ нельзя помещать в VITE_*.

### Чат

`POST /api/chat`, multipart/form-data:

- `messages`: JSON истории с role, content, attachments (имя/размер), productIds.
- `productId`: id обсуждаемого товара, если выбран.
- `files`: бинарные файлы текущего сообщения, повторяемое поле.

Ответ:

```json
{ "content": "Ответ по данным каталога", "productIds": [35819] }
```

Карточки сейчас поддерживают id из локальной выборки; для полного каталога нужно заменить источник товаров на API. Сервер должен хранить связь вложений с текущей сессией, если последующие вопросы ссылаются на старые файлы. Фронтенд повторно их не отправляет. В демо файлы не покидают браузер и не сохраняются в localStorage.

### Проверка остатков и корзина

`GET /api/products/:id/quote` возвращает актуальную цену, доступное количество и серверный идентификатор предложения:

```json
{ "quoteId": "server-issued-id", "productId": 35819, "stock": 3, "price": 49490 }
```

Числа здесь — пример контракта, не сведения о реальном остатке. UI открывает выбор количества; при нуле подтвердить нельзя. Только кнопка «Да, добавить» вызывает `POST /api/cart/items` с заголовком `Idempotency-Key` и JSON:

```json
{ "productId": 35819, "quoteId": "server-issued-id", "quantity": 2, "confirmed": true }
```

Ответ: `{ "cartUrl": "https://ekt.kz/actual-cart-path/" }`. Это пример, сервер должен вернуть реальный путь к актуальной корзине. Разрешаются только URL текущего origin или ekt.kz/www.ekt.kz. Оформление заказа не выполняется.

На бэкенде обязательны авторизация сессии, CSRF-защита, привязка quoteId к пользователю и сроку действия, повторная атомарная проверка цены и остатков с учётом уже добавленного количества, идемпотентность повторов. Клиентские проверки не являются защитой API. Сервер должен также проверять фактический формат, размер и безопасность вложений, ограничивать сроки хранения и не исполнять содержимое файлов. Неподдерживаемые форматы должны возвращать понятную ошибку.
