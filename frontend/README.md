# Фронтенд EKT Assistant

Этот React/Vite-интерфейс теперь подключён к FastAPI и ИИ в родительской папке. Полный запуск и ограничения описаны в `../README.md`.

- `npm ci` — установка.
- `npm run dev` — разработка; /api проксируется на 127.0.0.1:8765.
- `npm run build` — проверка TypeScript и сборка в dist.
- `npm test` — демо-сценарии и новый API-контракт.

Режим api включён по умолчанию. Для явного автономного демо задайте VITE_CHAT_MODE=demo. В режиме API источник товаров — backend; локальная выборка показывается только при загрузке или недоступности сервера. Ключи моделей хранятся исключительно в корневом .env.

Сохранены оформление, плавающий чат, выбор товара в контекст, сравнения автономного демо и загрузка нескольких файлов. Добавлены серверные предложения/подтверждения, страница корзины, распознавание вложений с редактируемым черновиком и сброс серверного контекста. Для реальных товаров без валюты в API настроено отображение в тенге (KZT); KRATNOST_MIN не считается правилом партии.
